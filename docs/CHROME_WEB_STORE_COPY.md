## Title Suggestion

Marketplace Focus - Facebook Reels Blocker

## Short Description

Block Facebook Reels so you can use Facebook for Marketplace, Groups, Messenger, friends, family, and regular browsing - without endless scrolling.

## Long Description Draft

Marketplace Focus is a lightweight, privacy-first Facebook Reels blocker for people who still need Facebook.

Use Facebook for Marketplace, Groups, Messenger, friends, family, and regular browsing without being pulled into endless Reels scrolling.

Features:

- Block Facebook Reels pages
- Hide or reduce Reels entry points
- Marketplace-friendly focus mode
- Quick pause when needed
- Hard Lock for stronger focus
- Scheduled focus windows
- Smart exceptions
- No account required
- No tracking
- No data selling
- Works locally in your browser

Marketplace Focus is not affiliated with Meta or Facebook.
