Marketplace Focus support

Short answer: use the Chrome Web Store support path for product issues, and include your browser, extension version, and the Reels behavior you expected to be blocked.

Marketplace Focus is a browser extension for reducing Facebook Reels distractions while keeping Facebook usable. Support requests are easiest to handle when they include the affected browser, extension version, blocking mode, and a short description of the page or entry point that was not blocked.

Browser compatibility

Marketplace Focus supports Chrome, with Edge and Firefox builds available for users who want the same Reels-blocking workflow across browsers.

For browser-specific notes, version context, and update flow, use the full browser support guide.

Troubleshooting steps

Start by confirming that the extension is enabled, then check whether Strict Focus Mode or Classic Facebook Mode is selected. If blocking is active only during certain hours, review your schedule settings.

If Reels still opens, include your browser name and version, Marketplace Focus version, selected blocking mode, whether Hard Lock or schedules are enabled, and a short description of the Facebook page or Reels entry point involved.

If the issue is about a missing block, describe whether Reels opened from a navigation item, feed card, direct URL, notification, or another path.

Privacy and data handling

Marketplace Focus does not require an account to use and does not use analytics, remote logging, tracking pixels, or external scripts. Extension settings such as blocking mode, exceptions, Hard Lock, and schedule preferences are stored locally in your browser.

Read the privacy policy for the current data-handling summary before installing or reporting an issue.
