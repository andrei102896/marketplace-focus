Browser support for Marketplace Focus

Short answer: Marketplace Focus supports Chrome, with Edge and Firefox builds available for users who want the same Facebook Reels blocking workflow.

Browser support FAQ

Do I need a separate account for different browsers?

Short answer: No account is required to use Marketplace Focus.

Install it in your preferred browser and configure settings in that browser environment.

Where should I start if I want the fastest setup?

Short answer: Start with Chrome via the Chrome Web Store path.

Then follow the setup guide to configure mode and focus controls.

Where can I report browser-specific issues?

Short answer: Use the Chrome Web Store support path linked on this site.

Include your browser, version, and behavior details so troubleshooting is faster.
